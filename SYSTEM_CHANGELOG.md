> This document records the evolution of the DevOps Learning Operating System (DLOS). Unlike Git history, it captures the intent and impact of changes to the learning system.

---

# Purpose

The changelog provides a structured history of improvements to DLOS so that major decisions, architectural changes, and new capabilities can be understood over time.

---

# Versioning Policy

DLOS follows Semantic Versioning.

- **Major (X.0.0):** Breaking changes to the learning system.
- **Minor (1.X.0):** New features, documents, or workflows.
- **Patch (1.0.X):** Corrections, refinements, or documentation improvements.

# Architectural Decision Log

## ADR-001

**Decision:** Separate governance, learning content, and portfolio artifacts.

**Reason:** Improve maintainability and scalability.

**Status:** Accepted

---

## ADR-002

**Decision:** Use DLOS.md as the repository constitution.

**Reason:** Establish a single governing document.

**Status:** Accepted

---

## ADR-003

**Decision:** Track operational progress in LEARNING_TRACKER.md instead of ROADMAP.md.

**Reason:** Keep the roadmap stable while allowing daily updates.

**Status:** Accepted
