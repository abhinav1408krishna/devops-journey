> This document records the evolution of the DevOps Learning Operating System (DLOS). Unlike Git history, it captures the intent, reasoning, and impact of changes made to the learning system.

---

# Purpose

The System Changelog provides a structured history of improvements to DLOS, ensuring that architectural decisions, workflow enhancements, and governance changes remain transparent and traceable throughout the project's evolution.

---

# Versioning Policy

DLOS follows **Semantic Versioning**.

- **Major (X.0.0):** Breaking changes to the learning system or repository architecture.
- **Minor (1.X.0):** New features, workflows, templates, or governance improvements.
- **Patch (1.0.X):** Documentation corrections, formatting improvements, and minor refinements.

# Architectural Decision Log
### ADR : Architectural Decision Record

## ADR-001

**Decision:** Separate governance, learning content, and portfolio artifacts.

**Reason:** Improve maintainability, scalability, and repository organization.

**Status:** Accepted

---

## ADR-002

**Decision:** Use DLOS.md as the governing constitution of the repository.

**Reason:** Establish a single authoritative document defining learning philosophy, standards, and governance.

**Status:** Accepted

---

## ADR-003

**Decision:** Track operational progress in LEARNING_TRACKER.md instead of ROADMAP.md.

**Reason:** Keep the roadmap stable while allowing daily learning progress to evolve independently.

**Status:** Accepted

---

## ADR-004

**Decision:** Adopt a multi-resource learning strategy.

**Reason:** No single learning resource provides sufficient theoretical depth, practical experience, and industry perspective.

**Resources**

- DLOS
- Official Documentation
- Nana Janashia
- KodeKloud
- Independent Projects

**Status:** Accepted

---

## ADR-005

**Decision:** Every technology module must conclude with an independent project.

**Reason:** Reinforce learning through implementation while continuously building a professional GitHub portfolio.

**Status:** Accepted
