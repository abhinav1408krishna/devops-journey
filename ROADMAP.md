## Phase 1 — Linux Fundamentals

Estimated Duration: 4–6 Weeks

Status: In Progress

Prerequisites:
- Repository Foundation

Objective:
Become comfortable administering Linux systems.

Why This Phase Matters:
Linux powers the majority of modern cloud and DevOps infrastructure.

Learning Outcomes:
- Navigate Linux confidently
- Manage users, groups and permissions
- Work with processes and services
- Write shell scripts
- Troubleshoot Linux systems

Topics Covered:
- Filesystem
- Shell
- Users & Groups
- Permissions
- Editors
- Package Management
- Processes
- Services
- Environment Variables
- Shell Scripting
- Logs
- Cron
- SSH

Hands-on Labs:
- File management
- User management
- Package management
- Service management
- Shell scripting

Mini Projects:
- Backup Script
- User Automation Script

Phase Project:
Linux Server Administration Lab

Deliverables:
- Lesson Notes
- Knowledge Book Updates
- Scripts
- Reflection
- Git Commits

Interview Preparation:
Linux administration fundamentals

Completion Criteria:
All lessons, labs and project completed.

Phase Exit Criteria:
Able to administer a Linux server independently.
